# Looma Float (loomafloat.ru) — анализ фронтенда, архитектуры и дизайн-подходов, со сравнением с io.net

**Объекты:** лендинг `loomafloat.ru/`, кабинет клиента `/app`, консоль администратора `/console`
**Дата обхода:** 19 сентября 2026
**Метод:** авторизованная сессия под администратором; обход всех экранов, чтение DOM / computed CSS / CSS-переменных, сетевых запросов и консоли; чтение исходников `web/src`. Никакие действия с побочными эффектами (аренда, деплой, отзыв ключей) не выполнялись — модалки открывались и закрывались.
**Ограничение:** кабинет и консоль снимались при ширине панели ~680px (адаптивная раскладка с верхней навигацией); десктопная сетка (`.shell` 216px + 1fr) описана по коду и токенам. Лендинг — при 1440 и 375px.
**Парный документ:** `ionet-frontend-analysis.md` — тот же формат для io.net; здесь на него ссылки в сравнительных разделах.

---

## 0. Резюме

Looma Float — **одно приложение на три поверхности**: лендинг, кабинет и консоль живут в одном Vite-бандле (259 KB JS + 31 KB CSS), на одной теме из ~30 семантических токенов и на самописном роутере в 20 строк. Это противоположность io.net, где лендинг (Next.js) и кабинет (Vite, 5.4 MB) — два разных продукта с разными командами.

| | Looma Float | io.net |
|---|---|---|
| Приложений | 1 (три поверхности) | 2 (+ второй деплой кабинета на `ai.io.net`) |
| JS на первую загрузку | 259 KB | 863 KB (лендинг) / 5 400 KB (кабинет) |
| Сторонних хостов | 1 (Google Fonts) | 32 (лендинг) / 34 (кабинет) |
| Тема | тёмная, одна, бирюза от знака | светлая (+ выключенная тёмная), Vercel-синий |
| Язык | русский, авторский тон | английский, маркетинговый тон |
| Главный визуальный приём | «станок»: фон-полотно, ткущееся по скроллу | белые плитки с «проводами», 3D-PNG |
| Живая демонстрация на лендинге | да, стриминг с метриками (ток/с, TTFT) | да, чат-инпут без метрик |
| Онбординг | по приглашению, аккаунты заводит админ | самообслуживание, WorkOS |
| Главные дефекты | утечка `<think>` в демо; обучающие группы админа видны клиенту как «арендованные кластеры»; карточки моделей врут о статусе | сломанный TaaS (CORS), преселект 8×H100 в рецепте, 5.4 MB бандл |

Главное различие в **формулировке ценности**: io.net продаёт *цену и отсутствие ожидания* («70% cheaper than AWS. Zero waitlists»), Looma продаёт *доступность мощности по требованию и честность устройства* («Мощность, когда она нужна» + три факта об архитектуре). Подробно — в разделе 5.

## 1. Общая архитектура

```
loomafloat.ru  —  один nginx, один Vite-бандл, один React-корень
│
├─ /            Landing.tsx      публичная главная + живое демо (/api/demo)
├─ /signin      SignIn.tsx       вход по почте и паролю (cookie-сессия)
├─ /app         Cabinet.tsx      кабинет клиента: расход, сеть, кластеры, ключи
└─ /console     Shell + 9 экранов  консоль администратора (роль admin)
                 Overview · Nodes · Models · Training · Ray · Tasks ·
                 Accounts · Keys · Release

Роутер: surfaceOf(pathname) → "landing" | "signin" | "app" | "console";
        внутри консоли экран хранится в state + localStorage("looma_screen"),
        URL не меняется.

API (same-origin, cookie + опциональный X-Looma-Admin-Token):
  /api/me  /api/demo  /api/usage  /api/compute  /api/capacity  /api/keys    ← клиент
  /admin/agents  /admin/tasks  /admin/groups  /admin/groups/{id}/health      ← админ
  /admin/train  /admin/accounts  /admin/rates  /admin/keys  /admin/release
  /admin/connect  /v1/models                                                 ← OpenAI-совместимый
```

### 1.1 Слой данных
- Единственный клиент — `lib/api.ts` (`get` / `send` / `grab`), ошибки нормализуются в `ApiError` с текстом из `error.message`.
- **`usePoll(path, everyMs)`** — единственный механизм получения данных: `setInterval` + `AbortController`; интервалы 4–30 с в зависимости от экрана. Стора нет; каждый экран сам опрашивает 2–6 эндпоинтов. Принцип (из комментария в коде): опрос обновляет состояние сервера и *никогда* не трогает состояние формы.
- `useAction` — обёртка «занято → тост об исходе → refresh»; все кнопки действий проходят через неё.
- Аутентификация: `whoami()` при каждой смене пути; 401 трактуется как «никто», а не как ошибка. Запасной вход — админ-токен в localStorage.

### 1.2 Сборка и доставка
- Vite, один чанк `index-*.js` (259 KB) + `index-*.css` (31 KB), без code-splitting — при трёх поверхностях это осознанный выбор: лендинг получает код консоли, но общий объём меньше одного чанка io.net.
- Шрифты — Google Fonts (IBM Plex Sans 400/500/600, IBM Plex Mono 400/500, Space Grotesk 500/600/700), `display=swap`.
- Ни одной картинки: все иллюстрации — inline SVG и CSS; лендинг — 192 DOM-ноды, консоль — ~130–400.
- Телеметрии нет вообще: ни аналитики, ни Sentry, ни пикселей.

### 1.3 Чего нет (и это видно)
- `<meta name="description">`, Open Graph, favicon-набор — отсутствуют; в шаринге страница будет без превью.
- `user-scalable=no` + `gesturestart.preventDefault()` — масштабирование запрещено жёстко (комментарий в `main.tsx` объясняет: Safari игнорирует meta). Для доступности это минус.
- URL консоли не отражает экран (`/console` для всех девяти) — нельзя дать ссылку на «Узлы» или открыть два экрана в вкладках.

## 2. Дизайн-система

### 2.1 Токены (`:root`, `web/src/theme.css`)
```
--bg-void            #03080a     страница
--bg-surface         #071115     панели
--bg-surface-raised  #0d1c22     карточки, hover
--overlay            #12242b     модалки/дроверы
--line / --line-soft #18313a / #101f25
--teal-core          #29c6de     accent (кнопки, ссылки, «ваш» узел)
--teal-bright        #7cf0ff     свечение, уто́к
--teal-dim           rgba(41,198,222,.14)
--ink-100            #e8f7fb     текст
--text-dim / --text-mute   .62 / .38 alpha
--ok #3ecf8e   --warn #e5b95c   --bad #f26d78   (+ *-soft подложки 12%)
--s1…--s6            4 / 8 / 12 / 16 / 24 / 32px
--r1…--r3            6 / 10 / 14px
--display  Space Grotesk   --sans  IBM Plex Sans   --mono  IBM Plex Mono
--shadow   0 8px 28px rgba(0,0,0,.5)
```
Комментарии в файле формулируют правила явно: «цвет означает состояние, а не палитру», «три веса важности текста вместо одного серого», «бирюза, а не сине-фиолетовый — тот узнаётся как цвет любого дашборда по умолчанию», «свечение — низкая насыщенность и большой радиус, а не яркость».

Сравнение с io.net: там 20 несемантических серых `--gray-light-100…1900` и `--gray-dark-100…2200`; здесь — 4 уровня поверхностей и 3 уровня текста с именами по роли. Обе системы держат `ok/warn/bad`; у Looma они дополнительно имеют `-soft`-подложки для бейджей.

### 2.2 Типографика
- Body 14px/1.5 IBM Plex Sans (io.net — 16px Inter).
- Шкала в консоли: 11 / 11.5 / 12 / 13 / 14 / 20px; заголовок страницы `h1` 20px Space Grotesk. Лендинг: h1 46px/700 с трекингом −4%, h2 26–30px/600, h3 20–24px, p 18/28.
- Моноширинный — только для того, «что читают по символам»: id групп, команды, адреса, версии. Это соблюдается везде (`.mono`, `<code>`).
- Все подписи разделов (`section > h2`) — капителью с разрядкой (`СЕТЬ`, `МОИ КЛАСТЕРЫ`, `ПОДНЯТЬ КЛАСТЕР`).
- Кнопки и строчные надписи — нижним регистром («снять», «отозвать», «детали», «арендовать»): узнаваемый авторский приём, снижающий визуальный шум таблиц.

### 2.3 Геометрия и поверхности
- Радиусы 6 / 10 / 14px (io.net: 4 / 6 / 8 / 16). Бейджи — pill 20px.
- `.glass` — карточка с полупрозрачным градиентом и внутренним свечением; `.card` — плоская. Stat-плитки на кабинете и консоли — `.glass`.
- Одна тень `--shadow`, используется на модалках/дроверах.
- Скроллбар стилизован (10px, `--line`) — на узких экранах горизонтальный скролл навигации консоли рисуется как заметная толстая полоса под шапкой (см. дефекты).

### 2.4 Движение: «ткацкая грамматика»
`components/Weave.tsx` — один примитив на все три поверхности с четырьмя стадиями: **основа** (направляющие, видны всегда), **зев** (нити расходятся), **уток** (светящийся челнок слева направо протаскивает контент), **прибой** (нити садятся с пружинным перехлёстом). Правила из кода:
- срабатывает единожды, при обратном скролле не повторяется;
- контент виден по умолчанию, скрипт прячет его только чтобы тут же показать — «украшение не имеет права прятать содержимое»;
- уважает `prefers-reduced-motion`.
Применяется: появление секций лендинга, раскрытие свежего API-ключа в кабинете (ключ «выткан» и «затыкается» при закрытии — визуальное подкрепление того, что он показывается один раз).

Фон лендинга `Loom.tsx` («станок») — не орнамент, а диаграмма одного факта: **от каждого узла ровно одна нить к оркестратору**, импульсы идут по ней в обе стороны, нить не упирается в центр, а становится утко́м полотна. Реагирует на наведение и на отправку демо-запроса.

У io.net анимаций как языка нет: CSS-transition, marquee логотипов, статичные PNG.

### 2.5 Компонентная база (`components/index.tsx`, 282 строки)
`Button(kind: default|primary|ghost|danger, size: sm)`, `Badge(tone, pulse)`, `StateBadge(value)` — словарь состояний → тон (running/ready → ok, pending/provisioning/loading → warn, failed → bad, cancelled/gone/idle → dim), `Field(label, hint)`, `FilePick`, `Stat`, `Empty`, `Bar`, `Modal`, `Drawer`, `Confirm`, `ErrorLine` (отличает «нужен админ-токен» от прочих ошибок), `Toasts` (ошибки живут 9 с, успехи 4 с), `Mark` (знак-«L» из переплетения, `currentColor`).
Без UI-библиотеки, без Tailwind, без Radix. Одна модалка, один дровер, одна таблица — везде.

Фон всех секций — `Loom` (станок). Навигация — якорная; на мобильном — бургер и полноэкранное меню.

### 3.2 Дизайн-язык
- Чёрный с бирюзовым подтоном; единственный акцент — `--teal-core`; 19 градиентов (все — свечения и стекло, а не «цветные полосы»).
- Primary-кнопка — бирюзовая с тёмным текстом и внешним свечением `0 10px 30px rgba(41,198,222,.8)`, 50px высоты, 10px радиус. Вторичных кнопок на лендинге нет.
- Заголовки Space Grotesk с отрицательным трекингом; абзацы 18/28 в 62% альфе.
- Нет ни одной растровой картинки, нет логотипов клиентов, нет тарифов — см. комментарий в `Landing.tsx`: «Нет отзывов и тарифов — их не существует, а придуманные видны сразу».
- Мобильный: H1 37.5px, без горизонтального скролла, карусель плиток по одной.

### 3.3 Демо
`GET /api/demo` → `{"model":"Qwen3-4B","nodes":2,"limit":220}`; `POST /api/demo` — стриминг. После ответа показываются метрики — это единственный лендинг из двух, который **доказывает** производительность числами, а не обещает.

### 3.4 Найденные дефекты
| # | Что |
|---|---|
| L1 | В ответ демо попадает блок `<think>…</think>` целиком — reasoning-трейс Qwen3 показан пользователю как часть ответа |
| L2 | Инпут демо предзаполнен `value="Привет!"` (не placeholder): пользовательский текст дописывается к нему («Привет!Что такое LoRA?») |
| L3 | Нет `meta description` / OG-разметки / `title` отличается только «Looma Float» |
| L4 | `user-scalable=no` + перехват pinch-жестов — нарушение WCAG 1.4.4 |
| L5 | Демо-ответ склеивает слова («эффективноFine-tune») — артефакт токенизации, не фронта, но виден на первом экране контакта |

### 4.1 Экран (один)
```
[ app-top ]  Looma Float             Панель (если admin) · Выйти
Мои ресурсы                                        [Арендовать кластер]
gihpeee@gmail.com
┌ ПОТРАЧЕНО ─────┐ ┌ СЕЙЧАС РАБОТАЕТ ┐ ┌ ТОКЕНОВ ВЫДАНО ┐
│ 0,00 ₽          │ │ 8               │ │ 0               │   .glass stat-плитки
│ по факту…       │ │ аренд           │ │ без потоковых   │
СЕТЬ      6 УЗЛОВ · 2 СВОБОДНО
          ▬▬▬▬▬▬ (fabric: по полосе на узел, цвет = состояние)
          легенда: свободен · под инференсом (0) · ваш (4) · занят другим
МОИ КЛАСТЕРЫ   таблица: кластер · узлов · с · состояние · [снять]
               «Счёт идёт, пока кластер держит ресурс. Снятие возвращает платформе
                модели, которые были подвинуты ради этой аренды.»
ПОТРЕБЛЕНИЕ    таблица: ресурс · GPU-часов · аренд · стоимость
ИНФЕРЕНС       (только если есть токены) модель · промпт · ответ
КЛЮЧИ API      [Создать ключ]  таблица: ключ (hint…) · создан · использован · [отозвать]
```
Модалка **«Арендовать Ray-кластер»**: Узлов (hint «по одной карте с узла»), Часов (hint «не больше 24 — потолок на одну аренду»), затем **Displacement-виджет** — те же полосы-нити, но в режиме предпросмотра: свободные узлы окрашиваются в «ваш», недостающие берутся из-под инференса и подсвечиваются как «подвинутые»; текст под ним меняется живо: «Свободных узлов хватает: 2 из 6» → «Свободно 2, не хватает 2. Платформа снимет столько же своих моделей и вернёт их, когда аренда закончится».

Свежий ключ показывается один раз в блоке `.notice` с «ткацким» раскрытием, кнопками «скопировать / убрать».

### 4.2 UX-решения
| Паттерн | Оценка |
|---|---|
| Три stat-плитки сверху: деньги · активность · объём | ✅ то, что клиент хочет знать первым |
| «Fabric» — состояние сети как полосы, один цвет = одно состояние | ✅ уникально; видно, хватит ли узлов, до открытия формы |
| Displacement-предпросмотр в форме аренды | ✅ лучший компонент продукта: показывает последствие действия до действия |
| Ключ показывается один раз, хранится хэш | ✅ стандарт; анимация подчёркивает необратимость |
| Хинты под каждым полем формы | ✅ |
| Пустые состояния с объяснением («Аренда считается по GPU-часам, инференс — по токенам») | ✅ |
| Нет цены в форме аренды | ❌ клиент не видит «сколько будет стоить» до нажатия; io.net показывает Total Cost inline |
| Нет истории/детализации по времени | ⚠️ одна сумма «потрачено» без периода |
| Нет способа пополнить баланс / нет понятия баланса | ⚠️ модель постоплаты не объяснена в UI |

### 4.3 Дефекты
| # | Что |
|---|---|
| C1 | **В «Мои кластеры» клиента попадают группы дообучения, запущенные администратором из консоли** (`group-e3f8869a3c`, `group-6c2628879d`, … — те же id, что у `looma-lora-*` в `/admin/groups`), все со статусом «работает», хотя обучение завершено 20+ часов назад. Лизы не закрываются вместе с задачей |

| C4 | Форма аренды не показывает стоимость и не проверяет верхний предел (`max=24` только на инпуте) |

## 5. Консоль администратора (`/console`)

### 5.1 Каркас
Десктоп: `.shell` — grid `216px 1fr`: слева `aside.side` (знак + «looma» + «N online», вертикальное меню-кнопки со счётчиками, внизу — поле «Админ-токен», бейдж «API отвечает/недоступен», почта и «выйти»); справа `main.main` с `.page` (max-width 1400). При ширине < ~900 сайдбар превращается в горизонтальную прокручиваемую шапку.
Заголовок вкладки — `«Экран · Looma»`.

### 5.2 Экраны
**Обзор** — «6 узлов на связи»; **радиальная схема** (центр-оркестратор, лучи к узлам, импульсы по лучам; легенда: простаивает / инференс / у клиента / обновляется); пять stat-плиток (Узлы · GPU свободно 12 из 12, 128.8 GB VRAM · Модели · Задачи · Версии агента); блок **«ТРЕБУЕТ ВНИМАНИЯ»** — список проблем с бейджем-источником («Models · looma-lora-6 ещё не отвечает»); таблица моделей.

**Узлы** — подзаголовок «звонят на loomafloat.ru:9000»; поиск + сегмент «все / простаивают / с проблемой» + счётчик «6 из 6»; таблица: узел (имя + «N s назад»), железо (карта, CUDA), GPU (n/m + бар), VRAM, состояние («0 задач»), снаружи («принимает» / «за NAT» / «symmetric NAT» / «вне сети»), агент (версия), «детали». **Дровер узла**: четыре stat (GPU, кэш окружений, кэш моделей, диск), «Железо» (key-value + «перечитать»), «Лог агента» (свёрнут), **«Канал к соседям»** (peer id, в сети узлов, дозвонимость, multiaddr-адреса, прямых / через оркестратор 275 / 550, RTT до соседа 43 ms, RTT до оркестратора 3.5 ms), «Агент» (версия, обновление, «перезапустить»).

**Модели** — «1 отвечает, 16 поднимается», [развернуть]; карточка модели: имя + бейдж + [спросить] [снять]; внутри — по строке на ранг: `rank 0 · nv3-f5c93f · слои 0–18 · готова · ready` с прогресс-баром фазы (в очереди 6% → окружение и веса 30% → стартует 60% → грузит веса 82% → готова 100%). **Модалка «Развернуть модель»**: HF-репо, имя для клиентов, точность (bf16/f16/f32), устройство (авто/cuda/mps/cpu), движок (transformers — переносимый / vLLM — батчинг, CUDA 12.6+), «узнать число слоёв», picklist узлов с VRAM и подсказкой «нет vLLM на: work-MS-7C60 — драйвер старше CUDA 12.6», «Стадий», чекбокс «резать слои пропорционально свободной VRAM». «Спросить» разворачивает inline-чат (инпут «привет», max tokens 128).

**Обучение** — «0 идёт, 9 всего», [дообучить модель]; карточка задания: имя · бейдж (done/stopped/failed) · `Qwen/Qwen3-0.6B · bf16 · LoRA r=16` · «20 ч назад» · «стадии: 0→nv3-758b97, 1→nv3-f5c93f» · результат («адаптер готов · 40 шагов, loss 0.1908» + чипы `adapter_config.json`, `adapter_model.safetensors` для скачивания) или ошибка человеческим языком («TimeoutError: стадия 1 не ответила на train_collect за 600 с», «задачи кончились, а результата нет — смотрите лог головы»). **Модалка «Дообучить модель»**: базовая модель (hint «bf16-чекпоинт: квантованные не подходят»), датасет `.jsonl` (hint формата messages), точность базы (bf16 / nf4 QLoRA), имя результата, сколько узлов + чипы узлов с VRAM, hint «модель режется по слоям между узлами; не влезает в один — берите больше», свёрнутое «подробно: адаптер и расписание».

**Ray** — «кластер под задачу: живёт, пока живёт задача, и умирает вместе с ней»; форма: узлы (picklist), узлов, карт на ранг, метка, библиотеки (textarea как requirements.txt), версия ray, точка входа `.py`; «Работают» (пусто); **шаблон задачи** с комментариями и «скопировать шаблон»; **таблица «Что здесь поедет, а что нет»** — форма задачи × обмен между узлами × на этом железе (независимые куски — да; конвейер по слоям — да; тензорный параллелизм — нет; DDP/FSDP — нет) с расчётом «7B = ~14 ГБ обмена на шаг, на 100 Мбит — двадцать минут за шаг».

**Задачи** — «11 выполняется», [запустить]; поиск + «активные / упавшие / все»; таблица: задача (id + узел · ранг), команда (mono, обрезана), состояние, время, результат, «детали»; ниже — **Группы**: группа (id + модель), ранги (`0: nv3-f5c93f 1: nv3-758b97`), [снять].

**Клиенты** — «кто пользуется платформой и по какой цене»; таблица (почта, роль, состояние, «отключить»), [Завести запись]; **Ставки** в копейках за GPU-час с пояснением «Ставка запоминается в аренде: поднятая завтра цена не перепишет вчерашние счета» — две карточки (looma-inference, looma-compute) с инпутом и «ok».

**Ключи** — «Ключи подключения: адрес оркестратора внутри ключа — владелец машины больше ничего не вводит»; таблица: id, метка, узлы (список имён), лимит (∞), «отозвать»; [выдать ключ].

**Обновление** — «Обновление агента · релиз не опубликован»; пустое состояние с инструкцией (`scripts/sign_release.py sign`, «Подпись ставится ключом, которого у оркестратора нет»); таблица узлов: версия, обновление (idle), что мешает.

## 6. Сравнение формулировок ценности: Looma Float vs io.net

### 6.1 Что говорит первый экран
| | Looma Float | io.net |
|---|---|---|
| H1 | «Мощность, когда она нужна» | «70% cheaper than AWS. Zero waitlists.» |
| Подзаголовок | «Считаем на распределённой сети GPU. Берите инференс или кластер — платите за использованное» | «H100s, A100s, and full clusters on demand. io.net is the GPU cloud built for AI teams who can't afford to wait.» |
| CTA | «Начать» | «Get Started» (+ announcement «Access +1,000 GPUs from $0.30/hr → Try Now») |
| Кому | не назван адресат; «вы» | «AI teams who can't afford to wait», «startups» |
| Обещание | доступность + оплата по факту | цена (число) + скорость доступа (число) |

io.net ставит в заголовок **две измеримые претензии** (70%, ноль ожидания) и повторяет «70%» шесть раз на странице. Looma ставит **качественное обещание** (мощность по требованию) и ни одного числа — до секции демо, где числа настоящие (31.2 ток/с, 0.30 с).

### 6.2 Как обосновывается ценность
| Аргумент | Looma Float | io.net |
|---|---|---|
| Цена | не названа нигде (тарифов нет — и в коде сказано почему) | таблица цен по 4 GPU × 3 продукта, дата актуальности, сравнение с AWS в карточках |
| Доказательство работы | живой стриминг с метриками скорости; «Qwen3 разрезана по домашним машинам» | живой чат без метрик; логотипы клиентов; «Trusted by top AI startups» |
| Устройство | три факта об архитектуре как аргумент доверия: одно исходящее соединение, платформа — первый клиент, песочница | устройство не объясняется («человеку безразлично, чем оно оркестрируется» — это ровно та позиция, которую Looma в комментарии к коду отвергает для себя) |
| Безопасность | «владелец машины сдаёт мощность, а не доступ к себе» — аргумент для поставщика | «SOC2, GDPR, confidential compute» — аргумент для корпоративного клиента |
| Социальное доказательство | нет | marquee логотипов, цитата CTO Leonardo.Ai |
| Дефицит | «Полотно уже соткано… Осталось выдать вам ключ» — приглашение, а не срочность | «Zero waitlists», «Get off the waitlist» — снятие срочности как ценность |

### 6.3 Тон и язык
- **Looma**: русский, авторская интонация, метафора ткачества сквозная (полотно, нить, уток, «полотно уже соткано»), нижний регистр в действиях, короткие подписи («Свой код на чужих картах», «Ваши веса — по запросу»). Копирайт **не обещает того, чего нет**: ни тарифов, ни отзывов, ни «99.9%». Аудитория подразумевается технической (знает, что такое инференс, Ray, LoRA r=16).
- **io.net**: английский маркетинг B2B-SaaS: числа, повторение ключевого обещания, глаголы действия («Deploy», «Launch», «Request»), «no waitlists / no lock-in / no hidden fees» триадами. Аудитория — стартапы с бюджетом на облако; технические детали спрятаны в рецепты и доки.

### 6.4 Где ценность продолжается внутри продукта
| | Looma Float | io.net |
|---|---|---|
| Лендинг → кабинет | тот же фон, те же токены, те же полосы-нити; «мощность когда нужна» превращается в Displacement-виджет: клиент видит, как платформа подвинет свои модели ради него | чёрная кнопка и HardwareCard общие; «70% cheaper» продолжается зачёркнутыми ценами конкурентов в карточках |
| Ключевое обещание в UI | «платите за использованное» → «Потрачено по факту, без списаний», «Счёт идёт, пока кластер держит ресурс» | «zero waitlists» → «Deploy now», Total Cost и «Pay & Deploy» за два шага |
| Где обещание ломается | стоимость аренды не показана до нажатия; ставки 0 ₽ | рецепт «на одну H100» приводит к 8×H100; TaaS не работает |

### 6.5 Вывод по ценностям
io.net продаёт **результат сравнения** (дешевле, быстрее), Looma — **доступность и честность механизма**. Первое лучше конвертирует холодный трафик, второе лучше удерживает того, кто уже понял, что покупает. Для Looma слабое место — отсутствие *любого* числа о цене или объёме сети до входа в кабинет; сильное — единственная на рынке демонстрация, где метрики берутся с реальных домашних машин, и текст, который не обещает несуществующего.

## 7. Сквозные дизайн-подходы Looma (что делает систему системой)

1. **Одна тема на три поверхности** — лендинг, кабинет, консоль неотличимы по цвету, шрифту, радиусам; переход «Панель ↔ кабинет» не ощущается как смена продукта.
2. **Цвет = состояние**: бирюза — действие и «ваше», зелёный/жёлтый/красный — ok/warn/bad, серый — «не про вас». Второго акцента нет.
3. **Хинт под каждым полем** — форма объясняет ограничение до ошибки («не больше 24», «bf16-чекпоинт: квантованные не подходят», «имя латиницей: Ray кодирует его в ASCII»).
4. **Предпросмотр последствия до действия** — Displacement в аренде, «нет vLLM на…» в picklist, таблица «что поедет» в Ray.
5. **Ошибки — фразами** («стадия 1 не ответила за 600 с»), с указанием, куда смотреть.
6. **Один примитив движения** с правилом «украшение не имеет права прятать содержимое».
7. **Данные важнее декора**: фон лендинга и полосы сети — диаграммы факта, а не иллюстрации.
8. **Явные отказы от паттернов** зафиксированы в комментариях к коду (нет тарифов, нет отзывов, нет роутер-библиотеки, нет `/admin`-префикса) — решения проверяемы.
9. **Всё на русском, включая идентификаторы в комментариях** — тон единый от кода до кнопки.

Против io.net: там система — это shadcn-токены и одинаковые hero-блоки; язык движения и объяснительный слой отсутствуют, зато есть многошаговые визарды, рецепты и монетизационные компоненты (кредиты, сравнение цен, чеклист онбординга), которых у Looma нет вовсе.

## 8. Рекомендации

### 8.1 Исправить (по убыванию заметности)
1. **Демо: вырезать `<think>`** до рендера (или сворачивать в «ход рассуждения»); убрать `value="Привет!"` → `placeholder`.
2. **Лизы обучения**: группы, поднятые из `/admin/train`, не должны становиться арендами клиента; закрывать лизу вместе с задачей (C1/A4).
3. **Статус карточки модели** выводить из стадий: все `cancelled/failed` → «снята/упала», без «спросить»; `done`-стадии обучения не показывать в Моделях (A1/A2).
4. Единый источник «что запущено» для Обзора, Моделей, Задач и Ray (A3, A5).
5. **Цена в форме аренды**: `узлов × часов × ставка` inline (как Total Cost у io.net), и объяснение постоплаты в кабинете (C3/C4).
6. Экран консоли в URL (`/console/nodes`) — deep-link и кнопка «назад».
7. `meta description` + OG для лендинга; убрать `user-scalable=no`.
8. Health-опрос групп — одним запросом вместо N+1.
9. Свёртка длинных списков узлов у ключа; поднять `--text-mute` до ≥4.5:1 для 11–12px.

### 8.2 Взять у io.net
- **Recipes**: «модель → готовая конфигурация» — в модалке «Развернуть модель» уже есть движок/точность/устройство; добавить пресеты по моделям с требованием VRAM (и, в отличие от io.net, без автопреселекта лишних узлов).
- **Inline-стоимость** и предупреждение о нехватке средств, не блокирующее путь.
- **Контекстная ссылка на документацию** в шапке консоли/кабинета.
- **Одно число на лендинге**, за которое можно отвечать: размер сети («6 узлов на связи» уже есть в консоли) или реальная скорость демо в hero, а не только внизу.
- Иллюстрированные пустые состояния — у Looma `Empty` текстовый; для кабинета нового клиента (ни ключей, ни аренд) можно дать один SVG в стиле знака.

### 8.3 Не брать у io.net
Многошаговые визарды ради визардов, автопопапы с лид-формами, «Request access» на продукты, которых нет, 20 серых токенов, трекеры, тёмный паттерн преселекта железа.
